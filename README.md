## Реализация

Модель описывает клиентов фитнес-клуба, тренеров, специализации, залы и записи на персональные тренировки. Данные хранятся в коллекциях в памяти. Пять запросов из задания реализованы с помощью LINQ и проверяются модульными тестами xUnit.

На данном этапе база данных PostgreSQL и брокер сообщений Kafka не используются, так как лабораторная работа № 1 посвящена созданию объектной модели и обработке данных в памяти.

| Тип | Назначение |
|---|---|
| `Person` | Базовый класс человека, содержащий паспортные данные, ФИО, пол и дату рождения |
| `Client` | Клиент фитнес-клуба: телефон и данные об абонементе |
| `Trainer` | Тренер: специализация и стаж работы |
| `Specialization` | Справочник специализаций тренеров |
| `Hall` | Зал фитнес-клуба: название и вместимость |
| `Training` | Запись клиента на персональное занятие с тренером |
| `Gender` | Пол человека: мужской или женский |

Классы `Client` и `Trainer` наследуются от общего базового класса `Person`. Специализация тренера представлена отдельным классом `Specialization` и используется как ссылка на элемент справочника.

Обязательные ссылочные свойства помечены `required`. Для проверки занятости зала запись о тренировке содержит дату и время начала занятия и его продолжительность. Публичные классы, свойства и перечисления снабжены XML-комментариями.
